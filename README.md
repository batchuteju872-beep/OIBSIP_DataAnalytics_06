# Wine Quality Prediction Analysis
**Oasis Infobyte Data Analytics Internship - Task 6**

## Project Overview
This project focuses on exploring and analyzing the chemical properties of wine to build machine learning classification models that accurately predict its quality score.

## Key Features Analyzed
* Fixed Acidity, Volatile Acidity, Citric Acid, Residual Sugar
* Chlorides, Free Sulfur Dioxide, Total Sulfur Dioxide
* Density, pH, Sulphates, Alcohol

## Machine Learning Models Trained & Evaluated
We implemented three distinct classification algorithms to determine the strongest predictor:
1. **Random Forest Classifier:** 70.31% 🏆 *(Best Performing)*
2. **Support Vector Classifier (SVC):** 63.76%
3. **Stochastic Gradient Descent (SGD) Classifier:** 50.22%
